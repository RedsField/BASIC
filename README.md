# BASIC
Ordinateur de vol simple, par l'enregistrement de données de vol ainsi que du guidage actif par servomoteurs

Les versions de l'ordinateur de vol embarqué sont nommées selon l'alphabet grec, et en fonction de leur fonctionalités.

BASIC alpha 1.0 ; première version de l'OV,
avec les fonctionalités suivantes;
- Arduino NANO pour piloter le système
- Carte micro-sd pour l'enregistrement
- Baromètre pour altitude
- Gyroscope pour orientation
- Magnétomètre pour position
- Borniers fixes pour gestion I/O E/S
